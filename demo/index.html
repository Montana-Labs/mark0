Kenapa pindah URL, bukan tombol pengubah tier?

Tier beban media ditetapkan pada tahap build, bukan runtime. Halaman SSG dibekukan menjadi berkas HTML saat build, sehingga tidak mungkin diubah tier-nya oleh interaksi di browser. Jika tier diganti lewat parameter runtime, CSR dan SSR akan menurut sementara SSG tidak — ketiga strategi tidak lagi diperlakukan simetris dan perbandingannya menjadi tidak adil.

Karena itu setiap kombinasi strategi dan tier merupakan build serta deployment yang terpisah, dengan kode sumber identik dan hanya berbeda pada satu variabel lingkungan (MEDIA_TIER / VITE_MEDIA_TIER).

Memverifikasi tier yang aktif: buka DevTools → tab Network → filter Img. URL gambar akan menunjukkan /media/<tier>/ beserta ukurannya.
